# ✅ 배포 전 회귀 체크리스트

매 배포 전 5분 안에 점검. 자동 테스트(`npm test`)가 못 잡는 통합 흐름 확인.

---

## 자동 검증 (먼저 실행)

```bash
npm run check    # tsc + eslint
npm test         # 단위 테스트
```

둘 다 통과 후 아래 매뉴얼 점검.

---

## 1. 신청서 흐름 (참가자 입장)

- [ ] `https://my-real-id-683cc.web.app/#/apply` 접속
- [ ] 이름·교회·연락처·참가비 단계 선택 후 제출
- [ ] **제출 완료 메시지 + 수정 링크** 표시되는지
- [ ] 운영자로 로그인 → **신청 대기함에 새 항목** 보이는지

## 2. 권한 분리

- [ ] 진행위원 비밀번호로 로그인 → 헤더에 **"진행위원"** 배지
- [ ] 참가자 관리 → **"참가자 추가" / "CSV 가져오기"** 버튼 보임
- [ ] 참가자 상세 클릭 → **수정·삭제** 버튼 보임
- [ ] 로그아웃 후 조회용 PIN으로 로그인 → 헤더 **"조회 전용"** 배지
- [ ] 위 편집 버튼들이 **숨겨짐** + "조회 전용 모드" 안내

## 3. 참가비 5단계

- [ ] 신청서에서 1차 등록(6만원) 선택 후 제출
- [ ] 참가자 관리 표에 **"1차"** 배지 + 색깔
- [ ] 상세 모달 → **"1차 등록 (6만원 완납)"** 풀 라벨
- [ ] 데이터 관리 → **"참가비 일괄 처리"** 미리보기에 1차 카운트 정확

## 4. 대시보드 통계

- [ ] 신청 1건 추가 후 대시보드 진입 → **전체 인원 +1**
- [ ] **참여 교회**도 정확 (중복 dedupe 확인)
- [ ] **공유 링크 카드** — 신청서 / 시스템 두 줄 모두 보임
- [ ] **카톡 미리보기 분리** — `/apply` vs `/system` 다른 OG (배포 후 카톡으로 직접 테스트)

## 5. 교회별 신청 현황 (통합)

- [ ] 사이드바에 **"교회별 확인" 메뉴 없음** (통합됨)
- [ ] 교회 카드 → **상세 보기** → 명단 모달 + 인쇄 버튼 작동
- [ ] **확인 완료** 토글 → 카드 색 변경
- [ ] 진행위원만 **"교회 편집"** 버튼 노출

## 6. CSV 가져오기

- [ ] 데이터 관리 → CSV 가져오기로 [docs/application-import-template.csv](application-import-template.csv) 업로드
- [ ] 미리보기에서 **이름·교회·연락처 인식** 확인
- [ ] 명단 추가 후 대시보드 카운트 증가

## 7. 데이터 관리

- [ ] **백업 다운로드** → JSON 파일 다운됨
- [ ] **참가비 일괄 처리** → 미리보기 통계 정확
- [ ] **변경 내역**에 위 작업들이 기록됨

## 8. 모바일·반응형

- [ ] 휴대폰 브라우저로 진입 → 사이드바 햄버거 메뉴
- [ ] 신청서 — 모든 입력란 잘 보임, 키보드 가림 없음
- [ ] 대시보드 카드 — 한 줄에 1~2개로 줄어듦

## 9. 카톡 공유 미리보기

- [ ] 본인 카톡으로 `https://my-real-id-683cc.web.app/apply` 전송
- [ ] **신청서 전용 미리보기** (og-apply.png + "참가 신청서") 표시
- [ ] 같은 카톡에 `https://my-real-id-683cc.web.app/system` 전송
- [ ] **운영 시스템 전용 미리보기** (og-system.png) 표시

## 10. 오프라인 / 동기화

- [ ] 인터넷 끊고 새로고침 → **오프라인 저장 중** 배지
- [ ] 신청자 추가 → 로컬에 저장됨
- [ ] 다시 연결 → **온라인 동기화** 배지 + 클라우드 자동 반영

- [ ] 진행위원 비밀번호·조회용 PIN 새로 설정
- [ ] 첫 진입 시 SetupScreen이 표시됨
