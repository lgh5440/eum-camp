# 현장 휴대폰 사용 안내

Firebase Hosting으로 배포한 뒤 운영진 휴대폰에서 아래 순서로 준비하세요.

## 1. 홈 화면에 추가

### iPhone

1. Safari에서 배포 URL 열기
2. 공유 버튼 선택
3. `홈 화면에 추가`

### Android

1. Chrome에서 배포 URL 열기
2. 메뉴 선택
3. `홈 화면에 추가` 또는 `앱 설치`

## 2. 인터넷이 약할 때

- 한 번 이상 앱을 열어두면 기본 앱 화면은 기기에 캐시됩니다.
- 참가자/체크리스트/교회 확인 변경은 먼저 휴대폰 로컬 저장소에 저장됩니다.
- 연결이 돌아오면 Firebase에 다시 동기화됩니다.
- 우측 상단 상태가 `오프라인 저장 중`이면 변경 후 같은 화면에서 잠시 기다렸다가 연결 회복을 확인하세요.

## 3. 권장 운영 방식

- 관리자 1명: `온라인 신청 대기함`, `데이터 관리`, `교회별 확인`
- 접수 담당: `현장 운영 모드`, `참가자 관리`
- 교회 담당자: 교회별 확인 링크만 공유
- 전체 운영진: `대시보드`, `비상연락망`

## 4. 행사 전 테스트

1. 운영진 휴대폰 2대에서 같은 배포 URL 접속
2. 한 기기에서 체크리스트 하나를 완료 처리
3. 다른 기기에서 5초 안에 반영되는지 확인
4. 비행기 모드에서 참가자 메모를 바꾼 뒤 다시 연결
5. 연결 회복 후 다른 기기에 반영되는지 확인
