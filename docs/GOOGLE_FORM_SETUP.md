# Google Forms 신청 접수 → 앱 자동 연동

청년/학생 수련회 2026 — 한 번만 셋업하면 신청자가 폼을 제출할 때마다 앱·대시보드·Firebase에 자동 반영됩니다.

> **소요 시간**: 5~10분 (Apps Script 자동 셋업) / 20분 (수동 셋업)

---

## 전체 흐름

```
참가자 (스마트폰)
   ↓ Google Form 작성 → 제출
Google Sheet (응답 자동 누적)
   ↓ CSV 게시
앱: 온라인 신청 대기함 (2분마다 자동 동기화)
   ↓ "명단에 추가" 클릭
참가자 명단 → Firestore (Firebase) → 다른 운영자 기기 자동 공유
   ↓
대시보드 / 조 편성 / 방 배정 / 차량 / 출력 / 체크인 ...
```

---

## A. Apps Script 자동 셋업 (권장)

### A-1. Apps Script에 코드 붙여넣기

1. [https://script.google.com/](https://script.google.com/) 접속 (수련회용 Google 계정)
2. **새 프로젝트** 생성
3. 왼쪽 코드 영역의 기본 `function myFunction()` 내용을 모두 지우고
4. 프로젝트 파일 [.sheet-build/setup-google-form.gs](.sheet-build/setup-google-form.gs) 의 내용 전체 복사 → 붙여넣기
5. 디스크 아이콘 또는 `Ctrl+S` 로 저장

### A-2. 실행

1. 상단 함수 선택 드롭다운에서 **`setupRetreatForm`** 선택
2. **▶ 실행** 클릭
3. 권한 검토 창이 뜨면:
   - 사용 계정 선택
   - "고급" → "안전하지 않음 (이동)" → 권한 허용
   - (Google 자체 도구를 자기 계정에서 실행하는 거라 안전합니다)
4. 잠시 기다리면 하단 **실행 로그** 에 다음이 출력됩니다:
   ```
   폼 편집 URL: https://docs.google.com/forms/d/.../edit
   폼 응답 URL (참가자에게 공유): https://docs.google.com/forms/d/e/.../viewform
   응답 시트 URL: https://docs.google.com/spreadsheets/d/.../edit
   CSV 게시 URL (앱에 등록): https://docs.google.com/spreadsheets/d/.../export?format=csv
   ```

### A-3. 시트 공유 확인 (1회)

자동 셋업에서 "링크가 있는 모든 사용자 보기"로 설정되지만, **반드시** 직접 한 번 더 확인하세요.

1. **응답 시트 URL** 열기
2. 우측 상단 **공유** 버튼
3. "일반 액세스" → **링크가 있는 모든 사용자 (뷰어)** 로 설정
4. 완료

## B. 수동 셋업 (Apps Script 권한이 부담스러운 경우)

### B-1. 구글폼 만들기

1. [https://forms.google.com/](https://forms.google.com/) → **빈 양식**
2. 제목: `청년/학생 수련회 2026 신청서`
3. 아래 항목을 순서대로 추가 (**제목은 정확히 입력** — 앱이 헤더를 자동 인식):

| # | 제목 | 유형 | 옵션 |
|:-:|:---|:---|:---|
| 1 | 이름 | 단답형 | 필수 |
| 2 | 교회 | 드롭다운 | 샘플제일교회, 샘플중앙교회, 샘플은혜교회, 샘플동산교회, 샘플소망교회, 샘플새싹교회, 샘플사랑교회, 샘플기쁨교회 |
| 3 | 구분 | 드롭다운 | 학생, 교사, 학부모, 운영진 |
| 4 | 학년 | 드롭다운 | 중1, 중2, 중3, 고1, 고2, 고3, 해당없음 |
| 5 | 성별 | 객관식 | 남, 여 |
| 6 | 연락처 | 단답형 | 필수 |
| 7 | 보호자 연락처 | 단답형 | 선택 |
| 8 | 식단/알레르기 여부 | 객관식 | 일반, 채식, 알레르기 있음 |
| 9 | 알레르기 상세 | 장문형 | 선택 |
| 10 | 참가비 납부 여부 | 객관식 | 미납, 완납, 부분납 |
| 11 | 특이사항 | 장문형 | 선택 |

> 헤더 명을 정확히 일치시키지 않아도 [src/utils/csvParser.ts](src/utils/csvParser.ts) 의 `ALIASES` 가 다양한 표기를 인식합니다. 그래도 위 표 그대로 쓰는 게 가장 안전합니다.

### B-2. 응답 시트 연결

1. 폼 상단의 **응답** 탭
2. 초록색 시트 아이콘 → **"새 스프레드시트 만들기"** → 만들기
3. 시트가 새 창에 열립니다 — 이름 확인 후 다음 단계

### B-3. 시트 공유 + CSV URL 만들기

1. 시트 우측 상단 **공유** 버튼
2. "링크가 있는 모든 사용자 (뷰어)"
3. 시트 URL 에서 **`/edit`** 앞부분을 복사
   ```
   https://docs.google.com/spreadsheets/d/AAABBB.../edit#gid=0
                                          ^^^^^^^^ 이 부분
   ```
4. CSV URL 형식으로 변환 (앱이 자동 변환도 해주지만, 직접 만들 경우):
   ```
   https://docs.google.com/spreadsheets/d/AAABBB.../export?format=csv
   ```

> 또는 시트 URL 자체(`/edit#gid=0` 형태)를 그대로 앱에 넣어도 됩니다. [Applications.tsx 의 getPublishedCsvUrl()](src/pages/Applications.tsx#L50-L57) 가 자동 변환합니다.

## C. 앱에 등록 (1회)

1. 앱에서 **온라인 신청 대기함** 메뉴
2. "Google Forms 응답 시트 가져오기" 패널에 **CSV URL** 또는 **시트 URL** 붙여넣기
3. **동기화** 클릭 → 정상이면 메시지 영역에 "추가됨 N건" 표시
4. **"2분마다 자동으로 Google Sheet 새 신청 가져오기"** 체크
5. URL 은 브라우저(localStorage)와 Firestore 양쪽에 저장 — 다른 운영자 기기에서 별도 등록 불필요

---

## D. 실제 운영 흐름

```
참가자가 카톡으로 폼 URL 받음
   → 폼 작성 → 제출
[앱 자동 동기화] (최대 2분 지연)
   → "온라인 신청 대기함" 에 새 카드 자동 추가
[운영자]
   → 중복 검사(자동), 정보 확인
   → "명단에 추가" 클릭
[앱]
   → 참가자 명단 + Firestore 저장
   → 대시보드, 조 편성, 차량, 방, 체크인 등 모든 화면에 자동 반영
   → 다른 운영자 기기/PC 화면도 자동 갱신
```

## E. 트러블슈팅

### "Google Sheet CSV를 가져오지 못했습니다"

| 원인 | 해결 |
|:---|:---|
| 시트가 비공개 | 공유 → "링크가 있는 모든 사용자 (뷰어)" |
| URL 형식 오류 | `/edit#gid=0` 형태든 `/export?format=csv` 형태든 둘 다 OK |
| 폼이 응답 시트에 연결 안 됨 | 폼 → 응답 탭 → 시트 아이콘 → 시트 만들기 |

### 한글 헤더가 인식되지 않음

[src/utils/csvParser.ts](src/utils/csvParser.ts) 의 `ALIASES` 객체에 자신의 헤더 표기를 추가:

```ts
'특이사항및 요청사항': 'notes',  // ← 사용 중인 헤더 → 표준 필드명
```

### 같은 사람이 두 번 신청

앱이 자동으로 **이름 + 교회 + 연락처** 를 비교해 "강한 중복 의심" / "중복 가능" 으로 표시합니다. 운영자가 검토 후 결정.

## F. 보안 고려사항

| 항목 | 권장 |
|:---|:---|
| 폼 응답 URL 공유 범위 | 카톡 단톡방, 교회별 담당자 정도까지만 |
| 시트 CSV 공유 | 링크가 있는 사람 보기 — 그래도 URL 노출 시 응답 데이터 일부 노출 가능 |
| 더 안전하게 | Apps Script `onFormSubmit` 트리거 → Firestore 직접 쓰기 (시트 게시 불필요). 별도 가이드 필요 시 요청 |
| 행사 종료 후 | 시트 공유 해제 + 폼 응답 받기 OFF |

## G. 자주 묻는 질문

**Q. 폼 한 번 만들면 끝인가요?**
A. 네. 운영진이 바뀌어도 같은 폼·시트를 계속 쓰면 됩니다. 단 새 운영자 기기에선 앱에 한 번 접속해 Firestore 동기화만 받으면 끝.

**Q. 폼 응답을 수정할 수 있나요?**
A. 자동 셋업한 폼은 응답 수정 허용. 다만 한 번 "명단에 추가" 한 후의 수정은 앱에 자동 반영되지 않으므로 운영자가 수동으로 수정해야 합니다.

**Q. 폼 항목을 더 추가하고 싶어요.**
A. 폼 편집 화면에서 직접 추가 가능. 단 새 헤더는 [csvParser.ts ALIASES](src/utils/csvParser.ts) 에도 매핑을 추가해야 자동 인식.

**Q. CSV 게시가 부담스럽다 — 더 안전한 방법?**
A. Apps Script `onFormSubmit` → Firestore 직접 쓰기 트리거. 작업 요청 시 별도 가이드 + 코드 제공 가능.
